# 片刻

**忙碌之间，留一片刻给自己。**

片刻是一款面向 Windows 的轻量本地 TXT 阅读器。用一个大小可调的小窗，接着读上次没读完的故事；也可以切换摸鱼模式，收起工具栏，让阅读界面融入桌面。

不需要注册，不需要额外安装 .NET。下载、解压，即可使用。

[下载片刻](https://github.com/194048210liang/PianKe/releases/latest) · [查看历史版本](https://github.com/194048210liang/PianKe/releases) · [反馈问题](https://github.com/194048210liang/PianKe/issues)

## 阅读，简单一点

- **连续阅读**：滚轮上下浏览，每本书独立记录进度，下次接着读。
- **章节目录**：在阅读窗口左侧展开，点击章节名称即可跳转。
- **章节预览**：先看看章节开头，不打断当前阅读、不改变进度。
- **最近阅读**：从工具栏快速找回最近打开的书。
- **快捷调整**：通过工具栏的 `Aa` 调整字号、摸鱼模式背景不透明度和背景取色。

## 摸鱼，低调一点

- **一行小窗**：自由调整窗口大小，最小可收缩到一行文字。
- **摸鱼模式**：隐藏工具栏，只留下正文；双击正文即可再次唤出工具栏。
- **颜色自定义**：背景和字体颜色自由调整，支持屏幕吸管取色。
- **透明背景**：摸鱼模式下可调整背景透明度，文字保持清晰。
- **窗口置顶**：通过图钉保持窗口在上层，仍然可以移动位置。
- **鼠标移入显示、移出隐藏**：置顶后可按需开启，作用于整个阅读窗口。
- **快速隐藏**：支持全局快捷键隐藏和恢复，也可以收进系统托盘。
- **图标自定义**：按喜好更换软件运行时图标。

> 片刻提供的是小窗阅读和外观调整，不是安全或隐私保护工具。请遵守所在场所的使用规定。

## 下载与使用

1. 打开 [最新版本页面](https://github.com/194048210liang/PianKe/releases/latest)。
2. 在 **Assets / 资源** 中下载名称类似 `PianKe-v1.0.2-win-x64.zip` 的文件，不要下载 `Source code`。
3. 将压缩包完整解压到你准备长期保存的本地文件夹。
4. 双击 **片刻.exe**，点击 **打开**，选择一本本地 TXT 小说。

正式便携版自带运行环境，首次打开时会尝试创建桌面快捷方式；已有同名项目不会被覆盖。请不要直接在压缩包中运行，也不要只移动快捷方式而删除原程序文件夹。

**运行环境：Windows x64。支持 32 MB 以内的 TXT 文件，暂不支持 EPUB、PDF。**

## 记住这几个操作就够了

| 想做什么 | 怎么操作 |
| --- | --- |
| 切换摸鱼模式 | 按 `F2` |
| 显示或隐藏工具栏 | 摸鱼模式下，**双击正文**；工具栏不占正文空间 |
| 移动窗口 | 按住正文拖动 |
| 调整窗口大小 | 拖动窗口边缘 |
| 跳转章节 | 点击工具栏的 **目录**，再点击章节名称 |
| 只预览章节 | 点击章节旁的 **预览**，不会改变阅读进度 |
| 快速调整外观 | 点击工具栏的 **Aa** |
| 隐藏窗口 | 点击 **−**、按 `Esc`，或使用设置中显示的全局快捷键 |
| 从托盘恢复 | 双击系统托盘中的片刻图标 |
| 真正退出软件 | 右键托盘图标 → **退出** |

> **点 × 是收进托盘，不是退出。** 全局隐藏 / 恢复快捷键以设置中实际显示的组合为准，默认优先使用 `Ctrl + Alt + R`。

## 设置，各归其位

- **阅读**：字号、背景色、字体颜色、背景透明度和滚动条。
- **摸鱼**：摸鱼模式、置顶后的鼠标显隐和全局快捷键。
- **通用**：自定义图标、操作说明、作者信息和软件更新。

常用操作放在工具栏，偶尔调整的选项留在设置里，让正文始终是主角。

## 更新由你决定

片刻支持检查 GitHub 上的新版本。你可以在 **设置 → 通用 → 软件更新** 中查看，也可以右键托盘图标，选择 **检查更新**。

- 发现新版后显示红点提示，**不强制更新**。
- 启动时的后台检查可以关闭，不会自动下载或安装。
- 点击 **下载并更新** 并确认后，才会下载更新包。
- 更新前保存阅读进度，校验通过后替换程序并重新打开。
- 联网失败不影响本地阅读，更新不会覆盖小说、阅读进度或个人设置。

请将软件放在当前用户可写的普通本地文件夹中，以便完成更新。`v1.0.0` 尚不支持在线更新，需要先手动下载新版替换一次。

## 本地阅读，数据留在本地

小说从本地文件读取，阅读记录与设置保存在：

`%LOCALAPPDATA%\WpfLocalReader\settings.json`

检查更新会访问 GitHub 的版本信息，下载更新时会联网获取包体；不上传小说正文、书名或阅读记录。

同一用户会话只运行一个片刻，重复打开会唤回已有窗口。测试新下载的版本前，请先通过托盘菜单退出旧版。
