片刻 v1.0.0 · 留给自己

【先看这几条】
1. 完整解压压缩包，再双击“片刻.exe”，无需安装。
2. 点“打开”选择电脑上的 TXT 小说，滚动鼠标滚轮阅读。
3. 按 F2 进入摸鱼模式，只留下正文。
4. 最重要：摸鱼模式下，双击正文显示工具栏，再双击隐藏。
5. 再按 F2，就能回到普通模式。

【移动、缩放和置顶】
按住正文或顶部文件名区域拖动，可以移动窗口。
拖动窗口四边、四角调整大小；摸鱼模式下可以缩成一行字。
点击图钉置顶：实心表示已置顶，空心表示未置顶。
置顶只是让窗口保持在其他普通窗口上方，仍然可以拖动。

【隐藏、找回和退出】
点工具栏“−”或在正文中按 Esc，可以隐藏窗口。
默认优先使用 Ctrl + Alt + R 隐藏／恢复；如被占用，会尝试其他组合。
请以“设置 → 摸鱼”里实际显示的快捷键为准。
点“×”只是收进托盘，不是真正退出。
双击右下角托盘图标可以找回窗口；图标可能藏在小箭头里。
真正退出：右键托盘图标 → 退出。

【鼠标移入显示、移出隐藏】
先点图钉置顶，再进入“设置 → 摸鱼”，开启“鼠标移入显示窗口，移出隐藏”。
鼠标进入阅读窗后，再移出约 0.3 秒，会隐藏整个阅读窗。
鼠标移回原来的位置，阅读窗就会重新显示。
普通模式和摸鱼模式都支持；未置顶时不可用。
工具栏仍由双击控制，不会因为鼠标移入而自动展开。
打开设置、帮助或正在拖动时，会暂停自动隐藏。
主动点 −、×、按 Esc 或快捷键隐藏后，不会因鼠标经过而弹出，请用托盘或快捷键找回。

【颜色、透明度和字号】
点击齿轮 → 外观，可以调整背景色、正文字色和字号。
“吸管”可以从屏幕取色；按 Esc 或右键可取消。
背景不透明度：100% 为实色，50% 为半透明，0% 为视觉透明。
透明度只影响摸鱼模式的阅读背景，文字不会一起变淡。
0% 保留极淡的鼠标操作底层，方便拖动和翻页，不是整窗鼠标穿透。
设置和工具栏保持实色。透明时如果文字看不清，可以手动调整字色。

【目录、预览和阅读进度】
普通模式底部可以打开“目录”和“最近”。
摸鱼模式也可以从“设置 → 更多”进入。
选中章节只预览，点击“跳转阅读”才会改变阅读位置。
每本书分别记住进度，下次打开继续阅读。
目前支持 32 MB 以内的本地 TXT，不支持 EPUB、PDF 或在线搜书。

【首次使用和更新】
首次打开默认显示工具栏，并弹出简短操作提示。
更多说明在“设置 → 更多 → 使用说明”。
新版只运行一个实例，重复打开会唤回已有窗口。
替换旧版前，请先从托盘右键退出所有旧版，再运行新版。
本版本尚未提供在线更新功能。
程序文件与阅读记录分开保存；设置位于 %LOCALAPPDATA%\WpfLocalReader\。
软件不会修改或上传小说原文件，也不会把小说正文打包进本压缩包。
